# Resultados obtidos na replicação

Os CSVs produzidos pela execução do pipeline do grupo replicado, sobre a subamostra de 30
repositórios de [`../subamostra.csv`](../subamostra.csv).

Os arquivos entram aqui **como saíram do pipeline do outro grupo**, sem nenhuma edição,
renomeação de coluna ou reordenação: a comparação com os resultados publicados por ele
parte do arquivo original. O diário em [`../diario_execucao.md`](../diario_execucao.md)
registra o comando que gerou cada um.
